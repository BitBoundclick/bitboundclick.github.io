## TL;DR
Download Minecraft mods **only from CurseForge or Modrinth**, match the mod version to your exact Minecraft version and mod loader (Fabric, Forge or NeoForge), and back up your world first. The safest, most useful UI mods are: Just Enough Items (JEI), Jade (block info), AppleSkin (hunger/saturation), Xaero's Minimap, and Sodium + Iris for performance. Avoid any site offering "free Minecraft Premium," cracked launchers, or mods as .exe installers — those are malware, not mods.

## The golden rule: where you download matters more than what you download
A legitimate mod is a .jar file you put in your `mods` folder. It is not an .exe, it does not ask for your Mojang/Microsoft password, and it does not come from a random blog with ten download buttons. CurseForge and Modrinth scan uploads, show download counts and version history, and let you see exactly which Minecraft versions a mod supports. If a mod is only on a shady mirror site, skip it — the real version is almost always on one of those two platforms.

Also: **never use a cracked launcher or a "free premium account" tool.** Those steal accounts. Use the official Minecraft Launcher, and use a mod launcher like Prism Launcher, Modrinth App, or CurseForge App to manage versions cleanly.

## 1. Just Enough Items (JEI) — the one mod every player should have
**What it does:** Shows every item and recipe in-game. Press a key, search for "diamond pickaxe," and see exactly what you need to craft it, without alt-tabbing to a wiki.
**Why it is safe:** One of the most downloaded Minecraft mods ever, open source, on CurseForge/Modrinth.
**Get it for:** Forge and NeoForge (the Fabric equivalent is Roughly Enough Items, REI — same idea).

## 2. Jade — what am I looking at?
**What it does:** A small overlay showing the block or mob you are pointing at, its name, and useful info like crop growth or a mob's health.
**Why it matters:** It replaces the old WAILA/HWYLA mods and stops the "what block is that?" guessing game, especially in modpacks with hundreds of new blocks.

## 3. AppleSkin — actually understand hunger
**What it does:** Shows saturation (the hidden hunger stat) and exactly how much hunger/saturation a food item will restore before you eat it. It also shows exhaustion effects.
**Why it matters:** Vanilla Minecraft hides saturation, so new players eat at the wrong times and starve in caves. AppleSkin makes food strategy visible.

## 4. Xaero's Minimap — a map that does not cheat
**What it does:** A clean minimap in the corner, with waypoints, death markers, and optional entity radar (turn radar off on servers that forbid it — check server rules).
**Fair-play note:** On multiplayer servers, only use minimap features the server allows. Some servers ban entity radar as an unfair advantage. Single-player: use whatever you like.

## 5. Sodium + Iris — performance and shaders, the safe way
**What it does:** Sodium massively improves FPS on Fabric by rewriting rendering. Iris adds shader support on top of Sodium, so you can use beautiful shader packs without the old OptiFine compatibility headaches.
**Why it is here:** It is a UI/performance mod in spirit — smoother frames *are* a better interface — and it is the modern, maintained alternative to outdated performance mods. If you are on Forge, the equivalent is Embeddium.

## 6. Inventory tweaks: Inventory Profiles Next / Mouse Tweaks
**What they do:** Sort inventories with one key, move stacks faster, and clean up chests without dragging every item by hand.
**Why they are safe:** Small, focused, widely used, and they do not touch gameplay balance — they just remove tedium.

## How to install UI mods safely (Fabric example)
1. Install the official Minecraft Launcher and run the Minecraft version you want once (so the game files exist).
2. Install Fabric Loader for that version from fabricmc.net, or use Prism Launcher / Modrinth App and create a Fabric instance.
3. Download mods from CurseForge or Modrinth only. Check: same Minecraft version, same loader (Fabric mods do not work on Forge, and vice versa).
4. Put the .jar files in the instance's `mods` folder. No .exe, no installer, no password prompt.
5. Back up your world: single-player worlds are in `saves` — copy the folder before adding mods.
6. Launch, test in a new world first, then load your main world.

If the game crashes on launch after adding a mod, remove the last mod you added and check its version/loader again — version mismatch causes 90% of mod crashes. See our startup-crash guide for the full checklist.

## Mods to avoid
- Any mod distributed only as an .exe or requiring you to disable antivirus
- "Free Minecraft" launchers, account generators, or cape/hack clients disguised as UI mods
- Mods promising unlimited diamonds, free Minecoins, or unlocked paid content — those are scams or server-ban bait
- Re-uploads on random sites that do not link back to the original CurseForge/Modrinth page

## FAQ

**Are Minecraft UI mods allowed on servers?**
Most UI mods (JEI, Jade, AppleSkin, minimaps without entity radar) are allowed, but every server has its own rules. Check the server's mod policy before joining with mods enabled.

**Do UI mods work on Bedrock (console/mobile)?**
No — Java mods do not work on Bedrock. Bedrock has add-ons and Marketplace content instead, which is a different system. This guide is for Java Edition.

**Will mods break my world?**
UI-only mods rarely do, because they do not add blocks or items. Still, back up before any mod change. Mods that *add* content can break a world if removed later — UI mods are the safest category to start with.

**Fabric or Forge?**
For UI and performance mods in 2026, Fabric (with Sodium/Iris) is usually lighter and updates faster. Forge/NeoForge is better if you want large content modpacks. Pick one, and only download mods for that loader.
